# Runner

校园/社区跑腿服务平台 —— 一个面向移动端的 Web 应用，用户可以发布和接取各类跑腿任务。

## 功能特性

- **快递代取** - 发布和接取快递代拿订单
- **团购代购** - 团购商品代买任务
- **超市代买** - 超市跑腿服务
- **自定义任务** - 用户自定义跑腿需求
- **订单广场** - 浏览和接取附近订单
- **用户系统** - 注册、登录、个人中心、订单管理
- **跑手申请** - 申请成为跑手
- **支付集成** - 支持支付宝 / 微信支付

## 技术栈

- **框架：** Vue 2 + Vue CLI 5
- **路由：** Vue Router 3 (Hash 模式)
- **状态管理：** Vuex 3
- **UI 组件库：** Element UI 2
- **HTTP 请求：** Axios

## 项目结构

```
src/
├── api/                 # 接口请求层 (Axios)
├── assets/              # 静态资源 (图片、CSS、JSON)
├── components/
│   ├── HomePage/        # 首页
│   ├── TakeOrder/       # 订单广场
│   ├── takeorder/       # 订单类型页面 (快递/团购/超市/自定义)
│   ├── User/            # 用户相关 (登录/注册/个人中心/订单)
│   ├── tools/           # 工具页面 (协议/商品/房间号)
│   ├── status/          # 状态反馈页 (成功/失败/警告/提示)
│   └── BottomTab/       # 底部导航栏
├── router/              # 路由配置 (含登录守卫)
└── store/               # Vuex 状态管理
```

## 快速开始

### 安装依赖

```bash
npm install
```

### 开发环境

```bash
npm run serve
```

### 生产构建

```bash
npm run build
```

### 代码检查

```bash
npm run lint
```
